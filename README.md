# Massacre at Millbrook — version G

> **⚠ Content warning — 18+.** This game contains graphic violence, gore and blood. It is not suitable for minors.

Halloween pixel-art slasher: five nights, five days in hiding, five rival psychopaths.
Open `index.html` in Chrome, Edge or Firefox: it works both from a web server (GitHub Pages, Netlify, itch.io…) and as a local file.
Keep the `a/` folder next to `index.html`.

Created by Alex MrGo. Code, art and effects by Claude Opus 5.5. Background music: Suno V6. "Good boy" voices: Kokoro TTS (Apache-2.0), reworked.
